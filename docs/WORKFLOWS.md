# 工作流

工作流属于现有服务，不是独立测试站。客户端使用标准 `npm run desktop:dev` / `npm run desktop:exe` 构建，无预研开关、独立身份或本机引擎。

## 使用

1. 在同一 App 选择「工作流」，自动连接 `https://api.cyapi.cyou/workflows/`，业务接口为 `/api/workflows/*`。
2. 手动输入 CYAPI API Key 登录。不会读取工具接入或 Agent 配置中的凭据；Key 不进入 URL、日志、工作流文件或浏览器持久存储。服务通过官方 usage 接口校验，登录会话有效期 30 分钟。
3. 选择工作流，创建草稿，准备参考图和描述。草稿可自动保存；画布修改需显式保存。
4. 显式启动任务，在队列查看进度，在结果中下载图片。当前是参考图拼贴模拟，非 AI 生成、不计费，不下载模型。

素材、草稿、任务和结果在服务端按 Key 隔离。同一 Key 重新登录可查询原历史。关闭客户端不取消已提交任务；关闭前请确认输入与画布已保存。登录会话在 Key 吊销时不会立即失效，请在客户端退出登录撤销当前会话。

网络故障时可在工作流页右上角选择「重新连接」，确认后重载工作台；未保存的输入可能丢失，已提交任务不会重新发送。也可选择「浏览器打开」，浏览器会话与桌面会话各自登录。

## 桌面安全边界

- 主 UI 保持本地；工作流采用主窗口内独立、顶层远程 WebView，而不是跨站 iframe，因此不放宽服务的 `frame-ancestors 'self'` 或 SameSite Cookie 策略。
- 地址由原生 `Service` 内置正式域名提供，不接受网页或环境变量传入登录地址。仅允许该 HTTPS origin 的工作流页面、结果下载和模板分享。
- 远程 WebView 无任何本机 IPC 权限。能力限定为 `main` WebView，而不是整个共享主窗口；原生命令入口另校验 caller label 与本地 UI origin。
- 桌面适配器仅处理固定页面、外观和导航锁。不传 Key、Cookie、文件路径或任意命令；上传通过用户文件选择框。点击下载后，图片 / 分享文件保存至系统下载目录的 `CYAPI-workflows/`，使用随机文件名，不覆盖已有文件；完成或失败会在工作台提示。
- 切换工具接入、打开全局设置/弹窗只隐藏远程 WebView，不重载、不重放任务，不管理引擎生命周期。

## 构建与验收

`npm test`、`npm run build`、`cargo test --manifest-path src-tauri/Cargo.toml`。Windows 便携版使用 `npm run desktop:exe`，只编译及收集本地产物，不自动上传或发布更新。

编译后可运行 `npm run test:workflows:desktop`，在隔离临时用户目录启动真实 Windows EXE，验证正式 HTTPS 登录页、无效 Key 拒绝、页面隐藏 / 恢复、外观与 IPC 隔离。测试仅为该进程开启 WebView2 调试端口，结束后关闭，不把调试开关写入正式配置。

有效生产 Key 的完整登录、画布、上传和结果下载仍需使用者验收。自动化可验证无效 Key 被拒绝与桌面 IPC 隔离，但不能用假 Key 冒充生产业务验收。
