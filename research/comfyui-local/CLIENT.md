# 工作流预研桌面版：本机体验说明

这是下一大版本的独立预研构建，**不是 1.2.5 的正式更新，不覆盖正式版**。最新架构已改为独立常驻服务；本目录旧 `desktop.py`、检查副本与测试脚本仅留作历史实验，不再是客户端主入口。

## 打开体验

先在仓库根目录启动服务一次：

```powershell
npm run workflow:service:start
```

等待 `ready` 后，打开研究版：

```text
F:\codex_prj\CYAPI-toolbox-client\output\workflow-research\client\CYAPI-Toolbox-Workflows-Research.exe
```

首次打开默认进入「工作流」，之后记住上次使用的工作台和页面。也可以用浏览器访问 `http://127.0.0.1:8188/workspace/`。当前 EXE 依赖开发机环境，不是可移机安装包；不要移动 / 删除 `output/workflow-research/{venv,comfyui}`。

### 两个平级工作台

- **工具接入：** 先选择「当前工具」，再使用原有模型接入、集成、Skill、MCP、环境、用量和日志。工具选择不会改变创作素材或任务。
- **工作流（Workflow）：** 第二个入口，侧栏是工作流库、草稿、任务队列、结果，不显示 Codex / Claude / OpenCode 选择器，不要求配置 Agent。
- 点击左上两个入口直接切换，不需要经过选择首页。两侧记住各自页面；切换只隐藏创作界面，不销毁草稿编辑或正在上传的图片。画布 / 对话框打开或上传中，创作页导航锁定，关闭画布后再跳页。
- 底部设置 / 使用帮助通用；全局外观同步到创作界面。服务连接与测试边界仍在创作内部设置中。独立浏览器使用自己的四个页签，桌面中不再重复显示。

## 体验顺序

1. 选择「产品生图」卡片，预览模板 / ComfyUI 原生画布，点击「创建草稿任务」。预览不会执行。
2. 上传几张参考图、填写画面描述，保存草稿；可关闭后从「草稿」继续。画布内编辑后在弹窗右上角点击「保存画布」，返回表单会同步内容。底部长提示条已移除，保存反馈在标题栏显示；弹窗打开不再滚动背景页面。
3. 点击「启动任务」，从「任务队列」查看执行 / 取消，从「结果」预览和下载。**当前输出是实际参考图的拼贴模拟，非 AI 生图，不理解描述。**
4. 新建自己的工作流，或从推荐模板创建副本，在原生画布编辑。分享文件仅带模板图，不带本次任务的描述或参考图。
5. 关闭画布、关闭整个客户端，再打开：已保存草稿、任务和结果仍在；服务 / 引擎实例不变，已提交任务可继续。服务网页无客户端 IPC 权限。
6. 显式重启服务后，模板 / 草稿 / 已完成结果持久保留；活跃任务标记中断，不自动重放。原生内存历史不会恢复。旧实验目录原样保留，不混入新任务库。

只有执行 `npm run workflow:service:stop` 才停止服务与引擎进程树。客户端不会代启、停止或自动重启服务。重启电脑后需再次独立启动；未就绪时显示断连，可点击重新连接。

## 代码、状态与日志

- 独立服务：[`../workflow-service/`](../workflow-service/README.md)，有直接 Python 运行方式、迁移说明、限制和测试入口，不依赖桌面 IPC。
- 默认状态 / 日志：`output/workflow-research/service/`；`service.json` 含本机合成控制令牌，**不要分享**，状态命令不输出令牌。
- 查看状态：`npm run workflow:service:status`。
- 只允许模拟图片、SaveImage、PreviewImage 三类节点执行，不开放任意模型或社区节点，不读取已有 Agent 凭据。

## 研究隔离与构建

- 独立应用标识 `com.cyapi.toolbox.research`、独立 `%LOCALAPPDATA%/CYAPI-toolbox-research/{home,data}`；正式 `1.2.5` 不变，禁止正式更新检查 / 下载 / 安装。
- 默认关闭的 Cargo `research-workflows` feature；只有 Vite `research` 模式显示工作流入口。
- `npm run desktop:research` 为开发窗口；`npm run desktop:research:exe` 仅构建本机 EXE，不打第三方环境包、不运行正式发布收集。
- 服务与客户端默认 `8188`。改端口、环境目录和完整操作见[服务 README](../workflow-service/README.md)。

当前不提供真实 CYAPI、模型选择、环境自动安装、公网鉴权、多用户隔离、生产持久幂等或 macOS 验收。**不要将 8188 暴露到公网**；服务迁移代码已独立，但部署安全与 GPL 边界需要另行完成。本轮未推送、发布或远程部署。
