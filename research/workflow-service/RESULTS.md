## 架构与实际行为

- 自包含 `research/workflow-service/`，直接 Python CLI `start / serve / status / stop`，不依赖 Tauri、Node 或旧 stdio runner；仓库 npm 命令只是快捷入口。
- 管理进程不 import Torch；一个常驻 CPU ComfyUI 提供官方前端 `1.55.18`、HTTP / WebSocket、队列和执行。Windows 虚拟环境可能存在启动器 / 实进程，不把多 PID 误算作多套引擎。
- 客户端内嵌服务工作台，只作健康检查，不启动子引擎。服务连接、日志和说明收在设置中；普通用户不必进入 ComfyUI 找结果。
- App 内两个平级工作台，创作侧栏为库 / 草稿 / 队列 / 结果，不显示工具选择器；工具侧保留原菜单，选择器称「当前工具」。纯创作启动不加载 Agent 路由或扫描工具安装；切换工作台 / 全局设置只隐藏创作 iframe，不销毁编辑和上传状态。全局外观与帮助共用，创作配色不从属于 Agent。
- 服务目录提供「产品生图」「灵感成图」；个人模板支持新建、副本、分享文件导入 / 导出。真实 API 图是权威输入，仅另存节点布局；草稿表单与原生画布保存双向同步，用 revision 防止旧窗口覆盖。
- 当前工作台仅支持一个 `CYAPIResearchServiceImage` 图片源，可编排原生 SaveImage / PreviewImage；不是任意工作流产品化。服务模板 / 任务只读，个人模板 / 未启动草稿可编辑；受管理画布的原生 Run 不提交，返回工作台显式启动。
- 原生画布底部长提示 / 保存条已删除。保存操作和载图 / 保存状态在弹窗标题栏，必要说明放在预览 / 草稿页；受管理画布隐藏全局多工作流页签，避免堆积旧会话的横向滚动。弹窗 flex 布局填满剩余视口、打开时锁背景，说明弹窗只滚动正文。保留画布拖动 / 缩放、必要工具 / 节点文本滚动；不通过隐藏所有滚动条掩盖内容溢出。
- 最多 6 张、单张 8 MB 参考图被解码、去元数据、缩图为 PNG；像素实际通过图片节点 → 本机模拟 HTTP → IMAGE → SaveImage 进入 768 × 512 结果。输出明确写 `NOT AI GENERATED`，只是参考图拼贴，既不理解描述也不生成新产品图；模板封面是插画。
- 服务 JSON 保存模板、草稿、任务、上传与结果。启动意图先落盘，同一草稿重复启动复用任务，单次 POST `/prompt`；状态未知不自动重试。服务重启将活跃任务标记 interrupted、不重放，完成结果仍可下载。JSON 不是生产级事务队列。
- 关闭画布或主客户端不影响常驻服务 / 已提交任务。显式停止服务才清理该服务的进程树；不接管已有 Python / ComfyUI，不全局杀进程。
- 没有使用真实 Key、读取 Agent 凭据、调用 CYAPI 或下载模型；未改 ComfyUI 核心。第三方环境未打入研究 EXE，未远程部署或发布。

## 桌面嵌入与权限边界

- 正式版 CSP 未改变；研究版只增加 `frame-src http://127.0.0.1:8188`，无远程 capability，无弹窗 / 顶层导航 / 消息转发 IPC 桥。新增 UI-only postMessage 通道精确检查双方 origin / source，仅固定四页导航、外观、当前页与锁状态；不接受任意 URL / 路径或原生命令，不传图 / 素材 / 凭据。
- 保存按钮与画布的通道仅位于同源工作台 / 当前画布 iframe 之间，双方检查精确 source / origin，只收保存 / 请求状态 / 状态回报；不转发到桌面。图数据仍由 ComfyUI 扩展直接 PUT 到服务，包含原有 revision，未放宽 IPC / CSP 或允许画布直接提交任务。
- ComfyUI 上游会拒绝跨站 iframe 初次文档导航。自有 middleware 只对精确桌面 Referer、GET `/workspace/`、iframe navigate、固定回环 Host、无 Origin 的请求提前返回公共静态首页；没有修改上游核心，没有放行跨站 API、JS、上传、文件或执行请求。API 集成测试覆盖允许 / 拒绝边界。
- Windows WebView2 会向子 frame 注入 Tauri bridge stub，因此不能用「对象不存在」或 Promise 超时证明隔离。只读探针实测为 `blocked-no-response`；另用主端创建的原生哨兵窗口验证 iframe 调用 `close-canvas` 不产生关闭副作用、主端同操作能关闭。
- 这些是固定版本下特定路径 / 副作用的实测及静态权限检查，不是任意恶意节点沙箱或完整安全审计。回环 Host / Origin、CSP 和节点白名单不能替代公网鉴权与隔离。

## 失败修复与回归边界

- 异步节点等待 HTTP 时原生 interrupt 原先不能及时终止，取消可能等到超时才失败。现轮询上游 interruption，并使用固定上游 `/api/jobs/{prompt_id}/cancel` 的原子身份检查；真实 API 取消验收覆盖运行中 / 排队中目标，其他排队任务能成功。
- 桌面首次 iframe 403 已通过上述静态文档窄入口修复，不通过关闭上游 Origin 检查解决。
- UI 脚本早期误把 `locator.evaluate()` 的 element 当成描述参数，产生 `[object HTMLBodyElement]` 验收草稿，修正为 `(_body, prompt)`；不是产品画布同步故障。其他脚本曾漏等异步编辑页渲染、PowerShell 管道损坏中文匹配，修正等待 / 编码后复跑，不把失败计成通过。
- 默认 Playwright headless Chromium 不存在，改用本机已装 Edge，没有为测试下载浏览器。
- 最终 EXE 首次自动启动后 CDP 尚未开始监听，连接出现一次 ECONNREFUSED；未计为通过。窗口就绪后完整桌面与重开测试重新执行通过。
- `npm test`：最新 83 通过、1 因缺私有数据跳过、0 失败；本次增加画布无覆盖层 / 限定保存通道与弹窗滚动静态回归。Prettier、JS 语法和 `git diff --check` 通过。本次仅改服务网页与测试 / 说明，不改 Rust / Python 服务实现或桌面打包内容，无需重建 EXE；前次研究 release 构建证据保留，未冒充本轮重建。
- 双工作台脚本首跑误用帮助按钮名称「关闭」，实际为「关闭对话框」而超时；修正定位后完整 7 项重新通过，不将首跑计为通过。
- 定向命名检查先遇到记忆的非库页面，又在页面已渲染但父窗口尚未保存导航状态时立即 reload；脚本改为明确进入库并等待存储确认后，3 项完整重跑通过。不是修改产品来伪造验证。
